# USB-C dual-UART + RS-485 adapter: Synth and KiCad files

Files for the LinkedIn post. Work in progress; not fabricated, not tested on hardware.

- `usb_uart.synth` - the design source Synth compiles (plus the two layout sidecars).
- `kicad/` - the generated KiCad 10 project after routing (schematic, PCB, BOM). Generated by `synth route usb_uart.synth --krt-allow-via-in-pad` with FreeRouting 2.4.1, on a Synth build with the connector-edge, pad-rotation and ground-pour fixes applied. Result: 26 nets routed, KiCad design-rule check 0 errors and 0 unconnected nets. Do not edit by hand; edit the `.synth` and re-export.
- `images/` - 3D render.

Made with Claude Sonnet 5.5 (claude-sonnet-5-5) in Claude Code. Synth MCP tools used: synth_language_reference, synth_validate. Firecrawl MCP used for datasheets. Export, routing and DRC ran through the synth and kicad-cli command lines.

Known limits: the U1 exposed pad uses via-in-pad (JLCPCB filled-via fabrication not confirmed); the USB pair is not impedance-verified; the USB-C connector has no 3D model in the render. An engineer must review before anyone builds it.

The design notes (parts list, jumper table, unverified items) are in `README.md` in this folder.
