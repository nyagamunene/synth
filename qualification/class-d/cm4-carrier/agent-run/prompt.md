Design a complete, manufacturable Raspberry Pi Compute Module 4 carrier PCB that accepts a 12 V input and provides a multi-rail power chain (5 V and 3.3 V) with reverse-polarity and overcurrent protection, and breaks out the CM4's 200-pin DF40 interface to a gigabit Ethernet magjack, HDMI, a USB 2.0 hub (USB2514B) with stacked USB-A ports, a microSD socket, a DSI/CSI FFC connector, and a battery-backed RTC (PCF85063ATL with a coin cell and 32.768 kHz crystal), routed on a 6-layer HDI stackup.
